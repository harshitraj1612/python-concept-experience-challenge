01For loopRepeat once for each item in a collection.ITEM-BY-ITEM
PYTHON CODE
1students = ["Asha", "Rohan", "Meera"]
2for student in students:
3 print("Welcome,", student)

Python takes the next value from students, runs the indented line, then continues until the list is done.

02While loopKeep repeating while a condition stays true.CONDITION-BASED
PYTHON CODE
1energy = 3
2while energy > 0:
3 print("Power:", energy)
4 energy -= 1

The condition is checked before each pass. Changing energy makes sure it eventually becomes false.

03Nested loopRun an inner loop for every pass of an outer loop.LOOP INSIDE A LOOP
PYTHON CODE
1for row in range(1, 4):
2 for seat in range(1, 4):
3 print(row, seat)

The outer loop selects a row. For each row, the inner loop visits all three seats before moving on.
