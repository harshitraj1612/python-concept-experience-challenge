Python Concept-to-Experience Challenge

Open index.html to start on Topic 09 (Loops in Python). Use “Switch topic” in the top-right corner to move among all 25 topic pages. Each page includes an explanation, a visual step simulator, code-line highlighting, Next/Back/Play/Pause/Reset controls, a speed slider, output, a quick check, editable starter code, and a Python Compile button.

Make the complete site live with the Python compiler
1. Create a GitHub repository and upload the contents of this folder to the repository root. Keep render.yaml, server.py, every topic HTML file, and topic-assets together.
2. In Render, create a new Blueprint and connect that repository. Render will read render.yaml and set up the Python web service. You can also create a Web Service manually with runtime Python 3, build command “python --version”, and start command “python server.py”.
3. Deploy the service. Render provides a public onrender.com URL when deployment completes. Open that URL, choose a topic, edit code, then click Compile code.

The server binds to 127.0.0.1:8765 for local use. On Render it reads the assigned PORT and listens on 0.0.0.0. The compiler syntax-checks and compiles Python to bytecode; it does not execute submitted code. It accepts source up to 32,000 bytes.

For a static GitHub Pages-only deployment, the lessons and simulators work, but the Python Compile button needs the Python backend above.
